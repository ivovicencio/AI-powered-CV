# Frontend de CVOLVE

Este directorio contiene la aplicación Angular 21 y la PWA de CVOLVE.

Para instalar el proyecto completo, iniciar frontend y backend, ejecutar pruebas y desplegar, consultá el [README principal](../README.md).

Comandos disponibles desde la raíz del repositorio:

```bash
npm run dev:front
npm run test:front
npm run build
```
